# Ameer Saadoon Khudhair Portfolio

A self-contained, bilingual professional portfolio for Ameer Saadoon Khudhair.

## Included

- English and Arabic one-page experience at `/?lang=en` and `/?lang=ar`
- Server-rendered language variants with RTL Arabic support
- Amiri Arabic typography
- ASK monogram branding
- Local CV PDF and logo assets
- Generic Node.js server and Dockerfile
- Production build output generated by `npm run build`

## Run

```bash
npm start
```

Open `http://localhost:3000/?lang=en` or `http://localhost:3000/?lang=ar`.

## Build

```bash
npm run build
```

The generated `dist/` directory contains the deployable static assets and server files.
